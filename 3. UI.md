## Bottom Tabs (Main Navigation)

* Sessions (Default Home Screen)
* Analytics
* Profile



#### Sessions Tab

* Start New Session (Button)
* Session History (List)

  * Session Name
  * Session Date
  * Session Exercises



#### Analytics Tab

* Overview

  * Month Calendar View

    * Highlighted days when worked out with colours that are assigned to your created workouts plus grey color for custom workouts (Days are clickable)

      * Clicking a day takes you to the session that was performed
  * Workouts this Month + How many up or down from last month
  * Workout Week Streak 
  * Weight Graph
  * Latest PR

    * Date
    * Exercise
    * Weight + How much it went up
* Exercises

  * List of all exercises (Clickable)

    * Clicking an exercise takes you to Exercise site

      * Exercise site:

        * PR

          * Date
          * Weight + How much it went up
        * Graph

          * Sets over time
          * Calculated 1 REP MAX Over time
        * Estimated Level (just for the big moves, compared to weight)

          * Beginner, Intermediate, Advanced, Elite
        * Total Sets Done
        * Total Volume Done
* Muscle Distribution

  * Pie Chart Tabs:

    * Percentage of sets done (Legs, Chest, Back, Shoulders, Core, Arms)
    * Power distribution (Based on PR analytics and normalized with estimated Level analytics) (Legs, Chest, Back, Shoulders, Core, Arms)
  * List of muscles (Ordered by amount of sets done)

    * For every muscle:

      * Amount of sets
      * % of all sets
* Performance
* Personal Records

  * PR for:

    * There are used for the Power Distribution analytics

      * 1 Leg exercise (Squat by default)
      * 1 Chest exercise (Bench press by default)
      * 1 Back exercise (Lat Pulldown by default)
      * 1 OVH exercise (OVH press by default)
      * 1 Biceps exercise (Dumbbell curl by default)
      * 1 Triceps exercise (Tricep Cable Extension by default)
      * 1 Core exercise (Cable Crunch by default)
* Export

  * Select Time period

    * Select mode: JSON, CSV OR EXCEL (.xlsx)



#### Profile Tab

* Personal Information
* Workouts
