## Core Entities



#### User

* User ID PK
* Name
* Gender



#### User Weight

* Weight Entry ID
* User ID FK
* Weight
* Date



#### Exercise

* Exercise ID PK
* Name
* Primary Muscles Worked
* Secondary Muscles Worked



#### Workout Template

* Workout Template ID PK
* Name



#### Workout Template Exercise

* Workout Template Exercise ID PK
* Workout Template ID FK
* Exercise ID FK
* Exercise Order Index
* Amount of Sets



#### Workout Session

* Session ID PK
* Template ID (optional) FK
* Name (Custom, But Workout Template Name as default)
* Date



#### Workout Exercises

* Session Exercise ID PK
* Session ID FK
* Exercise ID FK
* Exercise Order Index (Default from template)



#### Workout Exercise Sets

* Session Exercise Set ID PK
* Session Exercise ID FK
* Set Index
* Repetitions
* Weight
