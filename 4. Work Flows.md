## Work Flows



#### Create a Workout

1. Go to Profile
2. Go to Workouts
3. Create a workout
4. Enter Name
5. Choose / Create Exercises
6. Define default number of sets for each exercise
7. Save



#### Edit a Workout

1. Go to Profile
2. Go to Workouts
3. Go to intended workout
4. Edit Name
5. Edit / Add / Create Exercises
6. Edit Amount of default sets



#### Create a Session

1. Go to Home
2. Start Session
3. Choose Workout / Start Blank Workout
4. Choose Exercise / Create Exercise / Edit Exercise
5. Determine / Edit Amount of Sets
6. Enter Weight
7. Enter Repetitions
8. Give Custom Session Name or Leave Untouched (Defaults to Workout name if chosen or just "custom workout" if nothing else)
9. Save



#### Create an Exercise

1. Go to Profile
2. Go to Exercises
3. Create Exercise
4. Enter Name
5. Enter Primary Muscles Worked
6. Enter Secondary Muscles Worked
7. Save



#### Check Analytics

1. Go to Analytics
2. Go to Weight / Exercises / Distribution / Performance
